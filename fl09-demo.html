3. 4-Step Reproduction Guide for Strangers

Follow these 4 steps to reproduce the exact agent execution environment locally in under 5 minutes:

Step 1: Clone Repository & Setup Virtual Environment

Bash / Terminal 
git clone https://github.com/Sohila-Khaled-Abbas/flyrank-ml-internship-starter.git
cd flyrank-ml-internship-starter
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# Install required packages:
pip install pandas numpy scikit-learn python-docx

Step 2: Launch Self-Hosted Docker n8n Container

Docker Command 
docker run -d --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n n8nio/n8n:latest

Step 3: Import Workflow JSON to n8n

  1. Open http://localhost:5678 in your web browser.
  2. Navigate to Workflows ➔ Import from File ➔ select n8n/flyrank_content_refresh_workflow.json.
  3. Activate the production webhook URL: http://localhost:5678/webhook/flyrank-pipeline.

Step 4: Execute Agent Pipeline Handler

Python Execution Command 
python scripts/n8n_pipeline_handler.py

Enforced Safety Guardrails & Limitations

  • 🔒 Temporal Data Leakage Prevention: Target-derived fields (trend_direction, trend_pct, is_declining_label) are programmatically blocked from model feature matrices via hardcoded code assertions.
  • ⏸️ Confirmation Pause Guardrail: The agent is restricted from running automated git push origin main or file overwrites without explicit user confirmation.
  • 📍 Missing Rank Marker Imputation: Pages with missing search rank markers (avg_position = 0) are imputed to a default proxy position of 50.0.
