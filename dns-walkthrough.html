3. Plain-Language DNS Walkthrough

What is DNS?

The Domain Name System (DNS) is the internet's phonebook. Computers communicate across networks using numerical IP addresses (such as 185.199.108.153), whereas humans remember names (such as flyrank.ai). DNS translates human-readable domain names into computer-routable IP addresses.

🔍 Recursive Resolver

The browser's digital courier (operated by ISPs or public resolvers like Google 8.8.8.8) that receives requests and searches internet nameservers to locate IP addresses.

🏛️ Authoritative Nameserver

The official master database holding verified DNS records for a domain (e.g. FlyRank's DNS servers).

📍 A Record vs CNAME Record

An A Record maps a hostname directly to an IPv4 address. A CNAME Record (Canonical Name) acts as an alias pointing one domain name to another domain name.

4-Step Execution Flow: What Happens When Someone Types Your Domain

  1. Request Initiation: The user types sohilakhaled.flyrank.ai into their browser. The browser sends a query to the Recursive Resolver.
  2. CNAME Lookup: The resolver asks FlyRank's Authoritative Nameserver, which returns the alias: sohilakhaled.flyrank.ai ➔ sohila-khaled-abbas.github.io.
  3. Host Routing: The resolver follows the CNAME to GitHub Pages / Netlify edge servers, which identify the repository matching Sohila Khaled's site.
  4. HTTPS SSL Handshake: The host negotiates an automated TLS/SSL certificate (via Let's Encrypt), encrypting traffic and rendering the green padlock icon in the browser.
